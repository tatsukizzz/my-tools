# マークダウンメモ

Notion下位互換のライト版を目指した、マークダウンメモアプリです。モバイル利用を想定しています。

## 使い方

### そのまま使う（ローカル）
1. `index.html` をダウンロードする
2. ブラウザで直接開く（ファイルをダブルクリック、またはブラウザにドラッグ&ドロップ）
3. スマホの場合、ブラウザの「ホーム画面に追加」を使うとアプリのような見た目で使えます

インストールや会員登録は不要です。外部ライブラリ・CDNにも依存していないので、オフラインでもそのまま動作します。

### GitHub Pagesで公開する
1. このリポジトリを GitHub にアップロード（`index.html` / `icon.svg` / `manifest.webmanifest` の3ファイルをリポジトリ直下に配置）
2. リポジトリの Settings → Pages で公開ブランチを設定
3. 発行されたURLにアクセスすればそのまま使えます。スマホでアクセスして「ホーム画面に追加」すると、アイコン付きでアプリのように起動できます

## 主な機能

- 見出し・太字・斜体・引用・コードなどをボタンで入力（マークダウン記号を覚える必要なし）
- 入力しながらその場でプレビュー表示（編集／プレビューの切り替えタブ）
- キーボード上に追従するボタンツールバー、ボタンの並び順は設定から変更可能（ドラッグまたは▲▼）
- 元に戻す／やり直す、全文コピー
- 文字数カウンター（ページごとに上限を設定可能。カウンターをタップして変更）
- ページ一覧・新規作成・削除
- ライト／ダークモード
- Markdown（.md）／テキスト（.txt）形式で書き出し
- 全データのバックアップ書き出し・復元（他の端末へ持ち運ぶ用）
- 設定画面に使い方・免責事項・作者リンク（X / Booth）を掲載

## データの保存について

- 入力内容はブラウザの保存領域（localStorage）に自動保存されます。**この端末のこのブラウザ**に紐づく保存のため、別の端末やブラウザには自動では引き継がれません。
- ブラウザの閲覧履歴・サイトデータを消去すると、保存内容も消える可能性があります。
- 端末の乗り換えやバックアップには、設定内の「全データを書き出す」で書き出したファイルを保管し、別の端末で「ファイルから復元」してください。
- 保存に失敗した場合（保存領域の空き容量不足など）は、画面上に通知が表示されます。

## 動作確認環境

現状渡しです。**Chrome（Galaxy S22 / Android）でのみ動作確認**しています。
それ以外のブラウザ・OS（iOS Safari、PC版Chrome / Edge / Firefox など）では未検証のため、レイアウト崩れや一部機能の不具合が起きる可能性があります。

## 既知の注意点

- 外部ライブラリ・CDNには一切依存していません。マークダウン変換は自前実装のため、オフラインでも動作します。
- キーボード表示時にツールバーが追従する挙動は、ブラウザ・OSのバージョンによって多少ズレることがあります。
- Googleドライブ等への直接保存はできません。「全データ書き出し／復元」機能で代用してください。
- バックアップの復元時は簡易的な内容チェックを行っていますが、本アプリの書き出し機能で作成したファイル以外の読み込みは推奨しません。
